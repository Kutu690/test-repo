# 财政收入 FI 与 GDP 回归 —— 第 1–7 题答案

数据：1994–2014 年，n = 21。代码见 `hw_fi_gdp.do`。

## (1) 散点图与模型设定
`twoway (scatter FI GDP) (lfit FI GDP)` 显示两者呈明显的正向线性关系，设定模型：

FI = β₀ + β₁·GDP + u

## (2) OLS 估计结果

| 变量 | 系数 | 标准误 | t 值 |
|---|---|---|---|
| GDP | 0.23744 | 0.00275 | 86.32 |
| 常数项 | −10156.03 | 821.61 | −12.36 |

估计方程：**FI^ = −10156.03 + 0.2374·GDP**
（R² = 0.9975，F = 7451.14，S.E. = 2283.02）

## (3) 经济学含义
β₁ = 0.2374：GDP 每增加 1 亿元，财政收入平均增加约 0.2374 亿元（边际财政收入倾向约 23.7%）。
常数项为负，只是拟合直线的截距，GDP 为 0 超出样本范围，不作经济解释。

## (4) 经济学检验
理论上财政收入随 GDP 增长而增长，且增量不会超过 GDP 增量，故应有 0 < β₁ < 1。估计值 0.2374 满足该条件，符号与大小均符合经济理论。

## (5) 拟合优度检验
R² = 0.9975，调整 R² = 0.9973，说明财政收入 99.75% 的变动可由 GDP 解释，拟合效果很好。

## (6) 方程显著性检验（α = 0.05）
H₀: β₁ = 0。F = 7451.14 > F₀.₀₅(1,19) = 4.38，p ≈ 0.000，拒绝 H₀，方程整体显著。

## (7) 变量显著性检验（α = 0.05）
H₀: β₁ = 0。t = 86.32，|t| > t₀.₀₂₅(19) = 2.093，拒绝 H₀，GDP 对财政收入有显著影响。
（常数项 |t| = 12.36 > 2.093，也显著。）
